# Day 23 — Git Branching for DevOps

## Concepts Practiced

- git branch
- git switch
- git switch -c
- feature branch
- git merge
- git branch -d

## What I learned

Today I learned how to create and use Git branches.

A branch lets me work on changes safely without affecting the main branch immediately.

## Important Commands

git branch = show branches

git switch branch-name = move to another branch

git switch -c new-branch-name = create and move to a new branch

git merge branch-name = merge branch changes into current branch

git branch -d branch-name = delete a branch after merge

## DevOps Lesson

DevOps teams use branches to safely develop, test, review, and merge changes.
