# Day 25 — Git Remote Workflow for DevOps

## Concepts Practiced

- git remote
- git remote -v
- git pull
- git push
- origin
- main
- local repository
- remote repository

## What I learned

Today I learned how local Git connects to a remote GitHub repository.

## Important Commands

git remote -v = show remote repository URLs

git pull origin main = download latest changes from GitHub main branch

git push origin main = upload local commits to GitHub main branch

git status = check current Git state

git branch = check current branch

## Important Meaning

Local repository = project on my computer

Remote repository = project on GitHub

origin = default name for the remote GitHub repository

main = main branch

## DevOps Lesson

Before starting work, pull latest changes.

After finishing work, commit and push changes.
