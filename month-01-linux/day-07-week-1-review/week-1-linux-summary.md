# Week 1 Summary — Linux Foundation

## What I Completed

This week I studied the Linux foundation for DevOps.

I practiced:

- Basic Linux commands
- File management
- Permissions
- Users and groups
- Processes
- Services and logs
- Git and GitHub workflow

## Day 1 — Basic Commands

I learned how to navigate the terminal, create folders, create files, edit files, and read files.

Commands:

- pwd
- ls
- cd
- mkdir
- touch
- nano
- cat
- history

## Day 2 — File Management

I learned how to copy, move, delete, search, and inspect files.

Commands:

- cp
- mv
- rm
- find
- grep
- less
- head
- tail
- wc

## Day 3 — Permissions

I learned how Linux permissions work.

Important commands:

- ls -la
- chmod
- chown
- sudo

Important lesson:

- chmod changes permission
- chown changes owner/group
- sudo runs a command as root/admin

## Day 4 — Users and Groups

I created a test user and group.

Important commands:

- adduser
- su
- exit
- groups
- id
- groupadd
- usermod -aG

Important lesson:

- tomi is my sudo/admin user
- devtest is a normal test user
- normal users cannot run sudo unless they are in the sudo group

## Day 5 — Processes

I learned how to view and manage running processes.

Important commands:

- ps
- ps aux
- top
- htop
- jobs
- kill
- pkill
- fg
- bg

Important lesson:

A process is a running program.

## Day 6 — Services and Logs

I installed and tested Nginx.

Important commands:

- service nginx status
- service nginx start
- service nginx stop
- service nginx restart
- curl localhost
- tail
- tail -f

Important lesson:

When a service breaks, check status first, then check logs.
