## What I learned

Today I learned how to copy, move, delete, search, and inspect files in Linux.

## Why this matters for DevOps

DevOps engineers often work with configuration files, logs, scripts, Docker files, deployment files, and server directories. File management commands are required for daily server work and troubleshooting.

## Command Meanings

cp = copy files or folders  
mv = move or rename files  
rm = remove files  
find = search files by name or type  
grep = search text inside files  
less = view long files page by page  
head = show the first part of a file  
tail = show the last part of a file  
wc = count lines, words, and characters
