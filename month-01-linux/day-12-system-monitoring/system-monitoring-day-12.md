# Day 12 — System Monitoring Script

## Commands Practiced

- df -h
- free -m
- uptime
- hostname
- du -sh
- date
- whoami

## What I learned

Today I learned how to check basic system health using Linux commands.

## Command Meanings

df -h = show disk usage in human-readable format  
free -m = show RAM/memory usage in MB  
uptime = show how long the system has been running  
hostname = show server/computer name  
du -sh folder = show total folder size  
date = show current date and time  
whoami = show current user  

## Why this matters for DevOps

DevOps engineers check disk, memory, uptime, and server health regularly.

If a server has no disk space or memory, applications can fail.

## DevOps Lesson

Before fixing an application, check the server health first.
