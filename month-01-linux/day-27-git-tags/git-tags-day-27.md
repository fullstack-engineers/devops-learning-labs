# Day 27 — Git Tags

## Concepts Practiced

- git tag
- lightweight tag
- annotated tag
- git push origin tag-name
- git tag -d
- git push origin --delete tag-name

## What I learned

Today I learned how to create Git tags.

Tags are used to mark important project versions or releases.

## Important Commands

git tag = list local tags

git tag v1.0.0 = create a lightweight tag

git tag -a v1.0.1 -m "Release version 1.0.1" = create annotated tag

git push origin v1.0.0 = push one tag to GitHub

git push origin --tags = push all tags to GitHub

git tag -d v1.0.0 = delete local tag

git push origin --delete v1.0.0 = delete remote tag

## DevOps Lesson

DevOps teams use tags to mark release versions, deployment points, and rollback points.
