## Concepts Practiced

## What I learned

Today I learned how to validate a Docker Compose file using GitHub Actions.

## Important Command

docker compose config

This command checks whether docker-compose.yml is valid.

## Why this matters

A broken docker-compose.yml file can break local development, CI pipelines, and deployment workflows.

## DevOps Lesson

CI should validate configuration files before they are merged or deployed.
