# Month 2 Day 2 — GitHub Issues and Project Tracking

## Concepts Practiced

- GitHub Issues
- issue title
- issue description
- labels
- task tracking
- linking commits to issues

## What I learned

Today I learned how GitHub Issues are used to track tasks, bugs, improvements, and DevOps work.

## Why this matters for DevOps

DevOps engineers use issues to track infrastructure tasks, CI/CD problems, deployment bugs, monitoring alerts, and automation improvements.

## Good Issue Examples

Bug:

CI pipeline fails during Docker build.

Task:

Add GitHub Actions workflow for Bash script validation.

Improvement:

Improve README with setup and deployment steps.

## DevOps Lesson

Professional teams do not track work only in chat. They create issues, assign tasks, discuss the problem, and link commits or pull requests.
