# Month 2 Day 1 — GitHub Pull Request Workflow

## Concepts Practiced

- main branch
- feature branch
- pull request
- code review
- merge
- delete branch
- git pull

## What I learned

Today I learned the basic GitHub pull request workflow used by DevOps and development teams.

A pull request allows changes to be reviewed before they are merged into the main branch.

## Important Commands

git switch -c feature/month-02-day-01-pr = create and switch to a new branch

git push origin feature/month-02-day-01-pr = push feature branch to GitHub

git switch main = return to main branch

git pull origin main = pull latest main branch from GitHub

git branch -d feature/month-02-day-01-pr = delete local branch after merge

## DevOps Lesson

The main branch should stay stable.

Feature branches are used for safe changes.

Pull requests help teams review, test, and merge changes professionally.
